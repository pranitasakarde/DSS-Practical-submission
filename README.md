# Data Science and Statistics (DSS) Practicals

## Overview
This repository contains 12 practical assignments for the **Data Science and Statistics (DSS)** subject, implemented using Python and Jupyter Notebook.

The practicals cover data preprocessing, exploratory data analysis, statistical methods, data visualization, and fundamental machine learning algorithms.

## List of Practicals

| No. | Practical Name |

| 1 | Data Acquisition |
| 2 | Exploratory Data Analysis (EDA) |
| 3 | Identification of Missing Values |
| 4 | Missing Value Treatment |
| 5 | Statistical Description |
| 6 | Sampling and Population |
| 7 | Array Creation |
| 8 | Data Visualization |
| 9 | Measures of Central Tendency (Mean, Median, Mode) |
| 10 | Simple Linear Regression |
| 11 | Logistic Regression |
| 12 | K-Nearest Neighbors (KNN) Classifier |
